NETLIFY: ЗАГРУЗКА ПАПКИ
1. Распакуйте ZIP в отдельную папку.
2. Загрузите на Netlify папку, непосредственно содержащую index.html,
   images/ и assets/. Загружайте их вместе.

NETLIFY: ИЗ GITHUB
1. Поместите содержимое архива в корень репозитория.
2. Подключите репозиторий в Netlify.
3. Команда сборки не требуется. Publish directory: .
   Эти настройки уже указаны в netlify.toml.

GITHUB PAGES
1. Загрузите содержимое архива в корень репозитория.
2. В Settings → Pages выберите публикацию из вашей ветки, папка / (root).
3. Не переименовывайте папки images/ и assets/.

ПРОСМОТР НА КОМПЬЮТЕРЕ
